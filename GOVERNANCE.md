# Governance

## Maintainers

The specifications are maintained by ServiceNow's AI Platform Security team. The owners
are [@pierre-snow](https://github.com/pierre-snow) and
[@ramachandran-ramamur](https://github.com/ramachandran-ramamur). Maintainers review and
merge changes, sign the test vectors and publish versions.

## Draft and approved specifications

- Every version with a `-draft.N` suffix (for example `1.0-draft.1`) is a **Draft
  Specification** under the Community Specification License 1.0.
- A version published without that suffix (for example `1.0`) is an **Approved
  Specification**. The maintainers approve a version after the public feedback window
  described in [VERSIONING.md](VERSIONING.md).

## Changes

Changes are proposed as issues or pull requests, as described in
[CONTRIBUTING.md](CONTRIBUTING.md), and follow [VERSIONING.md](VERSIONING.md).
